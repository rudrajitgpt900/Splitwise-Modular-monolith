# Skill Selection

Use skills based on the task.

| Task | Required Skills |
|---|---|
| New Spring Boot service | architecture, spring-boot, api-design, testing, documentation |
| REST API | api-design, spring-boot, security, testing |
| Database change | database, spring-boot, testing, documentation |
| Redis | caching, infrastructure, observability |
| Kafka | messaging, infrastructure, observability, testing |
| Authentication | security, spring-boot, api-design |
| Production readiness | architecture, security, observability, infrastructure |
| Performance issue | architecture, database/caching, observability |
| Code review | code-review + relevant domain skill |
| New microservice | architecture, spring-boot, api-design, database, infrastructure, observability, security, testing, documentation |

Do not use unrelated skills unnecessarily.
